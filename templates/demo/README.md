# CLite public case file

A dispatch has vanished from Tahmid's CTF workspace on a rainy evening in Dhaka. A margin note, a river crossing and the green cursor mark the beginning of an original detective trail.

Start with:

    case
    cat CASEFILE.md
    cat casebook/padma-dispatch/README.md

Recover each scene's CLITE{...} evidence and submit it with `check CASE-ID FLAG`. A correct statement reveals the next lead. `hint CASE-ID` gives a nudge; `score` records recovered evidence without spoiling the route.

Some clues live in the workspace; others hide in this website's HTML, stylesheet, SVG metadata, crawler instructions and response headers. Use your browser's source view and Network tools, then return to the terminal with your evidence. You never need to scan or attack another website.

The references borrow from Bangladesh, science, folklore, idioms, detective fiction and cinema. The story and puzzle text are original; knowledge of the referenced books or films is optional. Every clue includes enough information to solve its technique.

Use `help` for the practice command subset. Pipes and redirects work, and you can keep a notebook:

    echo 'my observations' >> notes.txt

Uploads, workspace downloads and transcript saving are in the toolbar. Your case-progress.json travels with the workspace export. Short reconnects recover the current shell; files are temporary and can disappear after expiry or a server restart. In a fresh practice session, upload its exported case-progress.json and run `case restore` to resume your trail.

This is an offline practice shell rather than Bash. It never launches arbitrary Python or host commands. Team mode supplies the real Linux shell, compilers, debuggers, network tools and package installation.

The standalone encoding/log/JSON/strings exercises remain available as optional warmups. They are separate from the linked case.
