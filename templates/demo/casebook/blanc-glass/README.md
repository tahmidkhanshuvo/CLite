# Blanc Glass

The borrowed detectives

A bookshop keeper has labelled the evidence with famous fictional detectives. The notes are original; their methods are the clue.

At blanc glass, a folded note reads:
Only a verified courier is a witness. Search the dispatch log with grep.

Inspect dispatch.txt. Submit evidence with:
check blanc-glass 'CLITE{your_recovered_evidence}'

A correct statement reveals the next scene.
