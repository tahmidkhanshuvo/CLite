# Bangla Typewriter

The borrowed detectives

A bookshop keeper has labelled the evidence with famous fictional detectives. The notes are original; their methods are the clue.

At bangla typewriter, a folded note reads:
The witness read the mirror instead of the page. Try rev.

Inspect evidence.txt. Submit evidence with:
check bangla-typewriter 'CLITE{your_recovered_evidence}'

A correct statement reveals the next scene.
