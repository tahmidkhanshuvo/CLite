# Pitha Wrapper

The borrowed detectives

A bookshop keeper has labelled the evidence with famous fictional detectives. The notes are original; their methods are the clue.

Find parcel.message with jq, remove its JSON quotes using tr -d '"', then unwrap both Base64 layers.

Inspect parcel.json. Submit evidence with:
check pitha-wrapper 'CLITE{your_recovered_evidence}'

A correct statement reveals the next scene.
