# Hilsa Receipt

The borrowed detectives

A bookshop keeper has labelled the evidence with famous fictional detectives. The notes are original; their methods are the clue.

At hilsa receipt, a folded note reads:
Only one witness matches the SHA-256 fingerprint. Hash the witness files and recover that exact statement.

Inspect fingerprint.txt. Submit evidence with:
check hilsa-receipt 'CLITE{your_recovered_evidence}'

A correct statement reveals the next scene.
