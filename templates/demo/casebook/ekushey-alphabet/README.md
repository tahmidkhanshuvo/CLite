# Ekushey Alphabet

The borrowed detectives

A bookshop keeper has labelled the evidence with famous fictional detectives. The notes are original; their methods are the clue.

At ekushey alphabet, a folded note reads:
The packet is damaged, but printable evidence remains. Try strings.

Inspect fragment.bin. Submit evidence with:
check ekushey-alphabet 'CLITE{your_recovered_evidence}'

A correct statement reveals the next scene.
