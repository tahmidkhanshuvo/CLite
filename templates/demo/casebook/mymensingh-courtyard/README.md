# Mymensingh Courtyard

The missing dispatch

Rain closes over Dhaka. Tahmid's competition notebook contains a dispatch nobody remembers writing.

At mymensingh courtyard, a folded note reads:
Only one witness matches the SHA-256 fingerprint. Hash the witness files and recover that exact statement.

Inspect fingerprint.txt. Submit evidence with:
check mymensingh-courtyard 'CLITE{your_recovered_evidence}'

A correct statement reveals the next scene.
